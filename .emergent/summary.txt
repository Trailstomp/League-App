<product_requirements>
The application is a comprehensive league management platform for sports like lacrosse. It serves multiple user roles, including league administrators, team coaches/managers, and players.

**Core Requirements Implemented:**
- **League & Team Management:** Admins can manage league-wide data, including teams, players, seasons, and locations.
- **Customization:** Teams and league managers can customize their pages with logos, banners, and background images.
- **Image Storage:** The application leverages Google Drive for all image hosting (team logos, player photos, media galleries).
- **Team Communication:** Integration with GroupMe allows for team-specific and league-wide chat channels, event notifications, and messaging.
- **Event Scheduling:** Admins can create and manage game/event schedules.

**Recent Feature Enhancements & Bug Fixes:**
- **Team Admin Portal:** A dedicated interface for team coaches to manage their team's media, news, players, and users, with role-based permissions filtering the data they can access.
- **Advanced Event Management:**
    - Events can be set to recur on a daily, weekly, or monthly basis.
    - Automated event reminder notifications can be scheduled (e.g., 24 hours and 1 hour before an event).
- **Interactive RSVP System:** Users can RSVP to events directly within GroupMe notifications via interactive buttons, with responses tracked in the application.
- **Bug Fixes:** Numerous issues were resolved, including a blank team styles page, non-functional data saving (locations, events), incorrect image display, and buggy GroupMe chat message rendering.
</product_requirements>

<key_technical_concepts>
- **Full-Stack Application:** React frontend, FastAPI (Python) backend.
- **Database:** MongoDB for data persistence.
- **Styling:** Tailwind CSS.
- **Third-Party Integrations:**
    - **Google Drive API:** Used for all image and file storage. Requires OAuth 2.0 client credentials configuration.
    - **GroupMe API:** Used for team chat, notifications, and interactive bots/polls for RSVPs. Requires an access token and webhook setup.
- **API Architecture:** RESTful API with all backend routes prefixed with .
- **Deployment:** Containerized deployment to a Kubernetes environment via Emergent platform.
