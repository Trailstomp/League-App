# 🏅 League Admin User Guide

## Your Role
As a **League Admin**, you can manage all teams, events, and players across the league. You have access to most administrative functions but cannot modify system-level settings.

---

## What You Can Do

✅ Manage all teams and rosters
✅ Create and edit events for any team
✅ View and manage all players
✅ Access live scoring for any game
✅ Create news and announcements
✅ Manage photo galleries
✅ View payment information

## What Requires Full Admin

❌ User role changes (except within your scope)
❌ System-wide settings (SMTP, Stripe keys)
❌ Website branding/styling
❌ Database management

---

## Daily Responsibilities

### Event Monitoring
1. Check today's games on the ticker
2. Ensure venues and times are correct
3. Monitor RSVP counts for attendance planning
4. Verify scorekeepers are assigned

### Score Verification
After games are scored:
1. Review final scores for accuracy
2. Check player stats entries
3. Confirm game status is "Final"
4. Follow up on any disputes

---

## Managing Events

### Creating a Game
1. Navigate to Admin Portal → Events
2. Click "Add Event"
3. Select **Type: Game** or **Regular Game**
4. Choose Home Team and Away Team
5. Set Date, Time, and Location
6. Enable RSVP if attendance tracking needed
7. Save

### Creating a Tournament
1. Add Event with **Type: Tournament**
2. Enter tournament name and dates
3. List participating teams
4. Add venue information
5. Optionally create individual game events within

### Editing Events
- Click on any event to edit
- Change time/location as needed
- Add/remove teams
- Update status (Scheduled → In Progress → Final)

### Cancelling Events
1. Open the event
2. Change Status to "Cancelled"
3. Players will see "CANCELLED" badge
4. Send notification if time permits

---

## Managing Teams

### Viewing Team Rosters
1. Click on any team in sidebar
2. Go to "Roster" tab
3. See all players with positions and numbers

### Adding Players to Teams
1. Go to team's Roster tab
2. Click "Add Player"
3. Search for existing user
4. Set position and jersey number
5. Click Add

### Moving Players Between Teams
1. Remove from current team (Roster → player → Remove)
2. Add to new team (new team Roster → Add Player)
3. Player history is preserved

### Team Settings
Access team Settings tab to update:
- YouTube channel link
- Social media handles
- Team colors (for player cards)
- Logo and banner images

---

## Live Scoring

### Starting Live Scoring
1. Find the game event
2. Click "Live Score" or "Start Scoring"
3. Verify both team rosters loaded
4. Begin tracking

### During the Game
| Action | Button |
|--------|--------|
| Goal scored | Click "Goal" under scoring team |
| Shot saved | Click "Save" |
| Shot missed | Click "Miss" |
| Toggle shot clock | Use clock control |

### Player-Specific Stats
1. Click player name/photo in roster
2. Select stat type (Goal, Assist, Ground Ball)
3. Stat is recorded to that player

### Finishing a Game
1. Verify final score
2. Click "End Game" or "Mark as Final"
3. Stats are locked and saved

---

## Communication

### Announcements
1. Go to Admin Portal → News
2. Click "Add Announcement"
3. Enter title and content
4. Select visibility (All, Division, Team)
5. Publish

### Event Reminders
- Automatic reminders go out based on RSVP settings
- Manual reminders: Open event → "Send Reminder"

---

## Reports & Data

### Standings
- View at Admin Portal → Standings
- Automatically calculated from game results
- Sorted by division

### Player Statistics
- Individual stats on each player's card
- Team stats on team Stats tab
- League leaders on Admin Portal → Stats

### Attendance Reports
- RSVP data per event
- Export to CSV for analysis

## Tips for Success

📋 **Keep schedules current** - Update immediately when changes occur

📊 **Verify scores quickly** - Finalize game stats within 24 hours

📣 **Communicate proactively** - Announce changes before they affect players

🤝 **Delegate to coaches** - Let team coaches manage their own rosters

📸 **Encourage photos** - Gallery content engages the community

⏰ **Set reminders** - Use system reminders for important events

## Common Issues & Solutions

### "Game not showing on ticker"
- Check game has a date set
- Verify date is within ticker range
- Ensure game isn't cancelled

### "Can't edit another coach's team"
- League Admin can edit all teams
- Refresh page if permissions seem wrong
- Contact Admin if issues persist

### "Player stats not saving"
- Ensure game is not yet "Final"
- Check your internet connection
- Try refreshing and re-entering

### "Wrong score displayed"
- Open game event
- Edit scores directly
- Save changes
- Refresh ticker to verify
